# rmx.as

Short URLs for rmx.as, powered by Netlify.

## How it works

- **`_redirects`** – Defines all redirect rules. Add paths and destination URLs, one per line: `/path    https://destination.com`

## Deploying

```bash
npm install
npm run deploy
```

## Formatting

Formats the `_redirects` file to ensure consistent spacing and sorting.

```bash
npm run format
```
